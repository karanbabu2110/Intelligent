# KAOS 1.3.0

## Status

`1.3.0` is the cumulative Knowledge and RAG release of KAOS. Its annotated Git
tag is `v1.3.0`, and its GitHub Release publishes the versioned JAR, TAR, and ZIP
produced from verified merged `main`.

This checkpoint represents every verified capability from the evolutionary
reset through completed First Knowledge and RAG Capability Epic 005. It is not
a claim of production readiness, a stable public library API, permanent SQLite
compatibility, or completion of the broader KAOS vision.

## Included foundation, AI, conversation, and persistence

- one-goal-at-a-time development rooted at roadmap #814;
- one root Gradle/Java 21 application and one production entry point;
- bounded local Ollama prompt submission with validated streamed responses;
- selectable conversations with isolated ordered histories; and
- versioned local SQLite conversation persistence with restart restoration,
  atomic turn writes, and classified privacy-safe recovery.

These cumulative capabilities were previously checkpointed by `v1.2.0`.

## Included Knowledge and RAG capability

- admission of one regular UTF-8 `.txt` document up to 1 MiB;
- exact text extraction and deterministic overlapping chunks;
- explicit local Ollama embedding generation with validated bounded vectors;
- atomic version-1 SQLite storage of the document, model identity, chunks, and
  vectors under a configurable local data directory;
- deterministic cosine-similarity ranking of up to three chunks created by the
  same embedding model with matching dimensions;
- bounded, injection-aware grounded prompt construction with stable source
  labels;
- streamed grounded answer generation through the configured local chat model;
  and
- citation source coordinates printed only after clean provider completion.

## Run and verify

From the repository root with Java 21:

```powershell
./gradlew.bat clean verifyLocal --no-daemon --warning-mode=all
```

Run the complete local knowledge path with installed Ollama models:

```powershell
$env:KAOS_OLLAMA_MODEL = "qwen3:4b-instruct"
$env:KAOS_OLLAMA_EMBEDDING_MODEL = "embeddinggemma"
$env:KAOS_KNOWLEDGE_DATA_DIRECTORY = "D:\kaos-data"
./gradlew.bat --% run --args="knowledge-ingest \"D:\documents\notes.txt\""
./gradlew.bat --% run --args="knowledge-ask \"What does the document say?\""
```

The release build produces `KAOS-1.3.0.jar`, `KAOS-1.3.0.tar`, and
`KAOS-1.3.0.zip` under `build/libs` and `build/distributions`.

## Security, privacy, and data ownership

- AI and embedding traffic remain fixed to Ollama on `127.0.0.1:11434`.
- KAOS does not download models automatically; both model selections are
  explicit environment configuration.
- Source documents, exact chunks, and embeddings remain local under the
  configured knowledge data directory.
- Knowledge and AI failures do not echo questions, evidence, prompts, model
  names, vectors, provider bodies, database paths, SQL, or stack traces.
- Grounded answers may quote or summarize private source material on the local
  terminal; users control which documents they admit and which questions they
  ask.
- No remote provider, telemetry service, credential store, background worker,
  event bus, plugin system, or separate runtime service is introduced.

## Verification evidence

The Epic 005 exit tree passed all 11 `verifyLocal` tasks with 254 passing tests,
zero failures or errors, and one existing skip. Deterministic tests cross the
application, real Ollama HTTP client, loopback streaming protocol, and temporary
SQLite knowledge storage while asserting exact grounded prompt transfer and
ordered answer and citation output.

An installed-model demonstration used Ollama 0.32.1,
`embeddinggemma:latest`, `qwen3:4b-instruct`, one synthetic policy document, and
an isolated temporary database. Ingestion stored one document, chunk, and
768-dimensional embedding; `knowledge-ask` returned the correct synthetic
backup time with one source citation and exit code 0.

## Compatibility and limitations

- Knowledge storage schema version 1 is validated but has no permanent
  migration or backward-compatibility promise.
- Only regular UTF-8 `.txt` documents up to 1 MiB are supported.
- Retrieval has no relevance threshold or reranking and returns at most three
  compatible chunks.
- Citation labels identify evidence supplied to the model; KAOS does not verify
  generated claims or reject omitted, invented, or incorrect citations.
- Knowledge answers are not added to conversation history or persisted.
