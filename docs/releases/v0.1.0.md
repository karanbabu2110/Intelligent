# KAOS 0.1.0

## Status

`0.1.0` is the first useful local-AI development release of KAOS. Its intended
Git tag is `v0.1.0`, and the GitHub release remains a pre-release because KAOS
is still evolving before a stable `1.0.0` contract.

This release is a reproducible capability checkpoint, not a production-readiness
claim.

## Included capabilities

- one Java 21 application in the root Gradle project;
- safe application configuration and one-shot command-line handling;
- proportional coded errors and a complete local verification task;
- local Ollama reachability through a fixed loopback version endpoint;
- explicit validated model selection with no automatic download or fallback;
- configurable 2,048-65,536-token context windows with a measured 4,096-token
  default;
- explicit thinking `off`/`on`, with ordinary requests defaulting to `off`;
- bounded response generation: 512 tokens for ordinary requests and 2,048 for
  deliberate reasoning, with explicit validated overrides;
- one bounded non-streamed prompt request to local Ollama;
- safe differentiation between natural completion and a provider length
  boundary, without presenting partial output as complete;
- 97 automated tests plus build, packaging, status, and help verification;
- the living architecture website and evidence-backed benchmark records.

## Run and verify

From the repository root with Java 21:

```powershell
./gradlew.bat clean verifyLocal --no-daemon --warning-mode=all
```

With Ollama running locally and the recommended ordinary model installed:

```powershell
$env:KAOS_OLLAMA_MODEL = "qwen3:4b-instruct"
$env:KAOS_OLLAMA_THINKING = "off"
./gradlew.bat run --args=ollama-model
./gradlew.bat --% run --args="ollama-prompt \"Why is the sky blue?\""
```

The release build produces `KAOS-0.1.0.jar`, `KAOS-0.1.0.tar`, and
`KAOS-0.1.0.zip` under `build/libs` and `build/distributions`.

## Security, privacy, and data

- AI traffic is fixed to Ollama on `127.0.0.1:11434`; no remote provider or
  credential handling exists.
- KAOS does not log prompts, raw provider bodies, model output, thinking traces,
  configured model names, exception details, or stack traces through handled
  failures.
- The prompt remains visible to ordinary shell history/process inspection
  because this is a developer CLI, so secrets must not be entered there.
- No conversation, memory, knowledge base, file ingestion, or persistent user
  data is stored.
- The runtime JSON dependency is Jackson Databind `2.22.1`; no provider SDK,
  streaming framework, module, worker, or service is added.

## Compatibility

KAOS still has no stable public API, persistent-data schema, plugin contract,
or independently consumed library. Pre-1.0 source, command, and configuration
contracts may change when real capability evidence requires it. No data
migration is needed from `0.0.1`.

## Not included

- response streaming, visible incremental progress, or cancellation;
- generalized timeout/retry and provider error taxonomy;
- conversation history or persistence;
- knowledge/RAG, memory, tools, agents, browser/desktop automation, KAI, or a
  user-facing product interface;
- remote providers, credentials, deployment infrastructure, microservices,
  worldwide scale, or enterprise operational controls.
