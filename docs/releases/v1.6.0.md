# KAOS 1.6.0

## Status

`1.6.0` is the cumulative HTTP GET Tool release of KAOS. Its intended
annotated Git tag is `v1.6.0`, and its GitHub Release publishes the versioned
JAR, TAR, and ZIP produced from verified merged `main`.

This checkpoint represents every verified capability through completed
Feature 008.01. It is not a claim of production readiness, a stable public API,
unrestricted network access, web search, browser automation, general autonomous
agents, or completion of Epic 008.

## Included prior capabilities

- one root Gradle/Java 21 application and production entry point;
- bounded local Ollama prompts and persistent conversations;
- local SQLite conversation, knowledge, and memory state;
- complete local Knowledge and RAG with stable citations;
- explicit durable answer-detail memory with lifecycle and privacy controls;
  and
- one explicitly approved, bounded `read_local_file` tool path.

These cumulative capabilities were previously checkpointed by `v1.5.0`.

## Included HTTP GET capability

- one provider-visible function named exactly `http_get`;
- one model-selected absolute standard-port HTTPS URL;
- an explicit allowlist of exact host names through
  `KAOS_HTTP_ALLOWED_HOSTS`;
- rejection of malformed, credential-bearing, fragment-bearing, disallowed,
  local, private, link-local, multicast, unspecified, and reserved targets;
- an exact URL and external-disclosure prompt requiring `approve` or `deny`;
- one single-use approval grant before DNS resolution and HTTP execution;
- one foreground GET with no request body, credentials, cookies, custom
  caller headers, redirects, retries, caching, persistence, or background work;
- one successful supported strict UTF-8 response capped at 32,768 bytes;
- one local Ollama tool-result continuation with no tools advertised;
- stable content-safe diagnostics and a URL-free, content-free audit record;
- deterministic tests without public-network or installed-model dependency;
  and
- a separately approved live fetch and summary demonstration.

## Run and verify

```powershell
./gradlew.bat clean verifyLocal --no-daemon --warning-mode=all
```

Run the HTTP GET tool with an explicitly allowed host:

```powershell
$env:KAOS_OLLAMA_MODEL = "qwen3.5:4b"
$env:KAOS_HTTP_ALLOWED_HOSTS = "example.com,docs.oracle.com"
./gradlew.bat --% run --args="http-get \"Use http_get to fetch and summarize https://example.com/\""
```

The release build produces `KAOS-1.6.0.jar`, `KAOS-1.6.0.tar`, and
`KAOS-1.6.0.zip` under `build/libs` and `build/distributions`.

## Security, privacy, and ownership

- A question or model request is not permission; every GET requires separate
  approval for the exact normalized URL and external disclosure.
- Configuration restricts requests to exact hosts and standard-port HTTPS.
- Destination validation rejects known non-public resolved addresses before
  the request, but DNS can change between validation and the HTTP connection;
  complete DNS-rebinding resistance is therefore not claimed.
- Response text is bounded, treated as untrusted tool data, sent only to the
  configured fixed-loopback Ollama endpoint, and not persisted by this path.
- Denial, cancellation, invalid input, unsupported responses, and transport
  failures default to no access or no further disclosure.
- Audit and failure output omit the URL, query, response content, credentials,
  and provider body.

## Compatibility and limitations

- Supported responses are successful textual, JSON, or XML media types using
  strict UTF-8 and no more than 32,768 bytes.
- Search, crawling, redirects, browser rendering, JavaScript, authentication,
  arbitrary headers, downloads, multiple URLs, retries, and tool chaining are
  excluded.
- Model selection and installation remain explicit operator responsibilities;
  answer quality and resistance to hostile remote text remain model-dependent.
