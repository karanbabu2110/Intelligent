# KAOS 1.0.0

## Status

`1.0.0` is the cumulative first-AI-integration release of KAOS. Its intended
annotated Git tag is `v1.0.0`. It represents every verified capability from the
evolutionary reset through the completed First AI Integration epic, rather than
only the final feature or pull request.

This is the first complete local-AI capability milestone. It is not a claim of
production readiness, a stable library API, persistent-data compatibility, or
completion of the broader KAOS vision.

## Included evolutionary foundation

- one-goal-at-a-time development rooted at roadmap #814;
- one root Gradle/Java 21 application and one production entry point;
- package-first evolution with evidence gates before modules, repositories, or
  services;
- validated local configuration, one-shot commands, safe coded diagnostics,
  deterministic tests, packaging, and the `verifyLocal` checkpoint;
- the evidence-based living architecture website.

## Included first AI integration

- fixed-loopback Ollama reachability with no remote endpoint or redirects;
- explicit validated model selection with no automatic discovery, download,
  fallback, or substitution;
- bounded context windows, explicit thinking off/on, and bounded response-token
  selection;
- one bounded prompt submitted to one local model;
- incremental UTF-8 NDJSON answer streaming with each validated chunk displayed
  exactly once and assembled into one bounded final answer;
- content-free thinking progress while raw reasoning remains hidden;
- backpressure, total and inactivity deadlines, interruption cancellation,
  provider/local limits, and clean terminal completion validation;
- phase-specific, privacy-safe error guidance before and after visible output;
- deterministic application-to-client-to-loopback-provider integration tests;
- a real packaged application demonstration using installed
  `qwen3:4b-instruct`, exact `KAOS_END_TO_END_OK`, exit `0`, and empty stderr.

## Run and verify

From the repository root with Java 21:

```powershell
./gradlew.bat clean verifyLocal --no-daemon --warning-mode=all
```

With Ollama running locally and an ordinary model already installed:

```powershell
$env:KAOS_OLLAMA_MODEL = "qwen3:4b-instruct"
$env:KAOS_OLLAMA_CONTEXT_WINDOW = "4096"
$env:KAOS_OLLAMA_THINKING = "off"
$env:KAOS_OLLAMA_RESPONSE_TOKEN_LIMIT = "512"
./gradlew.bat run --args=ollama-model
./gradlew.bat --% run --args="ollama-prompt \"Why is the sky blue?\""
```

The release build produces `KAOS-1.0.0.jar`, `KAOS-1.0.0.tar`, and
`KAOS-1.0.0.zip` under `build/libs` and `build/distributions`.

## Security, privacy, and data

- AI traffic is fixed to Ollama on `127.0.0.1:11434`.
- KAOS does not persist prompts, responses, reasoning, credentials, conversation
  state, or user data.
- Safe diagnostics exclude prompts, provider bodies, model output, reasoning,
  configured model names, exception details, and stack traces.
- The developer CLI prompt may remain in shell history or process inspection;
  it is not a secret-input surface.
- Jackson Databind `2.22.1` is the only direct production runtime dependency.
- No SDK, reactive framework, event bus, worker, plugin system, database,
  separate service, or remote provider is introduced.

## Compatibility and limitations

`1.0.0` establishes the current one-shot CLI and local Ollama configuration as
the first complete KAOS capability baseline. KAOS still has no independently
consumed library API, plugin contract, persistent schema, migration contract,
or production deployment guarantee.

This release does not include conversation history, persistence, knowledge/RAG,
memory, tools, agents, browser/desktop automation, KAI, a product interface,
remote providers, credentials, or distributed deployment. It performs one
foreground prompt with no retry or resume.
