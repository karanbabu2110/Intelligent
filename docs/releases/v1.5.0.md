# KAOS 1.5.0

## Status

`1.5.0` is the cumulative First Tool Integration release of KAOS. Its intended
annotated Git tag is `v1.5.0`, and its GitHub Release publishes the versioned
JAR, TAR, and ZIP produced from verified merged `main`.

This checkpoint represents every verified capability from the evolutionary
reset through completed Epic 007. It is not a claim of production readiness, a
stable public API, unrestricted filesystem access, general autonomous agents,
or completion of the broader KAOS vision.

## Included prior capabilities

- one root Gradle/Java 21 application and production entry point;
- bounded local Ollama prompts and persistent conversations;
- local SQLite conversation, knowledge, and memory state;
- complete local Knowledge and RAG with stable citations; and
- explicit durable answer-detail memory with lifecycle and privacy controls.

These cumulative capabilities were previously checkpointed by `v1.4.0`.

## Included First Tool Integration capability

- one provider-visible function named exactly `read_local_file`;
- one model-selected relative path using a supported text-based extension;
- mandatory explicit-root metadata validation before content access;
- an exact resolved-path and disclosure prompt requiring `approve` or `deny`;
- a single-use approval grant and one revalidated strict UTF-8 read attempt;
- a complete 2,048-byte maximum result with no truncation or partial output;
- one Ollama assistant-tool-call and tool-result continuation with no further
  tools advertised;
- stable content-safe tool and provider diagnostics;
- one random, path-free, content-free audit identity with decision and outcome;
- deterministic integration coverage across the command, filesystem boundary,
  and loopback Ollama protocol; and
- README tables covering all current KAOS environment variables and command
  argument shapes.

## Run and verify

```powershell
./gradlew.bat clean verifyLocal --no-daemon --warning-mode=all
```

Run the first tool with one explicitly allowed root:

```powershell
$env:KAOS_OLLAMA_MODEL = "qwen3:4b-instruct"
$env:KAOS_TOOL_READ_ROOT = (Resolve-Path ".").Path
./gradlew.bat --% run --args="read-local-file \"Explain src/main/java/io/kaos/app/KaosApplication.java\""
```

The release build produces `KAOS-1.5.0.jar`, `KAOS-1.5.0.tar`, and
`KAOS-1.5.0.zip` under `build/libs` and `build/distributions`.

## Security, privacy, and ownership

- A question or model request is not permission; the user must separately
  approve the exact resolved file for every attempt.
- The operation is restricted to one direct file below one explicit local root.
- File content is bounded, treated as untrusted tool data, sent only to fixed
  loopback Ollama, and never persisted by the tool path.
- Denial, cancellation, invalid input, and failures default to no access or no
  further disclosure.
- Audit and failure output contain no path or file content beyond the exact path
  intentionally displayed in the local approval prompt.

## Compatibility and limitations

- Supported extensions are `.txt`, `.md`, `.log`, `.java`, `.kt`, `.kts`,
  `.gradle`, `.json`, `.xml`, `.yaml`, `.yml`, `.properties`, and `.csv`.
- Compound and binary formats such as `.doc`, `.docx`, and `.pdf` are excluded.
- There is no directory listing, multiple-file operation, tool chaining,
  automatic retry, remote provider, or general tool framework.
- Model selection and installation remain explicit operator responsibilities;
  answer quality and resistance to hostile file text remain model-dependent.
