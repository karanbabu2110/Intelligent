release identity. It includes the evolutionary foundation, local AI,
conversations, and complete local persistence rather than only Feature 004.07
or its final pull request.

## Reproducible validation

Run from the repository root with Java 21:

```powershell
./gradlew.bat properties --console=plain --no-daemon
./gradlew.bat clean verifyLocal --no-daemon --warning-mode=all
Get-ChildItem build/libs,build/distributions -File
Get-FileHash build/libs/KAOS-1.2.0.jar -Algorithm SHA256
Get-FileHash build/distributions/KAOS-1.2.0.tar -Algorithm SHA256
Get-FileHash build/distributions/KAOS-1.2.0.zip -Algorithm SHA256
git diff --check
```

Release preparation must verify:

- Gradle reports version `1.2.0`;
- all tests pass with no failures, errors, or skips;
- all 11 `verifyLocal` tasks execute successfully;
- `KAOS-1.2.0.jar`, `KAOS-1.2.0.tar`, and `KAOS-1.2.0.zip` are rebuilt;
- repository-relative release and architecture links resolve;
- the architecture status matches completed Epic 004; and
- `git diff --check` passes.

## Publication procedure

1. Review and merge the `1.2.0` release checkpoint pull request.
2. Fast-forward local `main` to the exact merge commit.
3. Rerun complete validation and compute final artifact hashes.
4. Create annotated tag `v1.2.0` with annotation
   `KAOS 1.2.0 - Local Persistence` at that verified `main` commit.
5. Push only the `v1.2.0` tag.
6. Create the GitHub Release from that tag using the reviewed release notes.
7. Upload `KAOS-1.2.0.jar`, `KAOS-1.2.0.tar`, and `KAOS-1.2.0.zip`.
8. Verify the local and remote tag targets, annotation, release assets, hashes,
   and clean repository state.

## Limitations and next checkpoint

The version identifies the complete Local Persistence capability baseline; it
does not claim production readiness, a public library API, permanent SQLite
schema compatibility, remote providers, or distributed operation.

Completed Epics 000-004 remain immutable release evidence. Epic 005 — First
Knowledge and RAG Capability is next approved but is not included or active in
`1.2.0`.
